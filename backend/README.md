# Backend — Gym Manager

Esta carpeta va a contener la API REST desarrollada en Node.js, usando el módulo `http` nativo (sin frameworks externos) y el driver oficial `mongodb` para el acceso a la base de datos. La autenticación usa sesiones por cookie `HttpOnly`, respaldadas por la colección `sesiones`, y `bcryptjs` para el hash de contraseñas.

El código se implementará en la etapa de desarrollo del MVP (ver Sección 16 del README principal). Para esta entrega (Diseño y Módulos) no se sube implementación, solo el diseño y la documentación.
